パドックノート 仕様v1

観察モード(設定で切り替え)

簡易モード:馬体/気配/動き/総合の4項目(各◎○△×、総合のみ必須)
玄人モード:各カテゴリ内に詳細項目を展開
馬体:毛づや、張り、太め/細め、発汗
気配:落ち着き、耳・表情
動き:歩様、踏み込み、首の使い方
共通:ひとことメモ(自由入力)、馬具メモ(玄人のみ)

基本フロー
レース登録 → パドックで観察入力 → レース後に着順入力 → 統計ダッシュボードで的中率を確認

統計

簡易:カテゴリ別の的中率
玄人:項目別の的中率

技術:Next.js / TypeScript / Tailwind / Supabase、モバイルファースト
